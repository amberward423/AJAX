# AJAX

A JavaScript project for practising web development concepts, including AJAX and working with asynchronous requests.

## Technologies Used

- JavaScript
- Node.js
- npm
- ESLint
- Prettier

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/amberward423/AJAX.git
   ```

2. Navigate to the project directory:

   ```bash
   cd AJAX
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

### Running the Project

Run the main JavaScript file with Node.js:

```bash
node main.js
```

The current `main.js` file contains a simple greeting function that prints `Hello World!` to the console.

## Development Tools

- **ESLint** — for identifying potential issues in JavaScript.
- **Prettier** — for consistent code formatting.
